1. Packet Definition Layer

Defines:
packet layout
field sizes
bit positions
meaning of values

Decides:
how many bits each field gets
what each field means
byte order
max packet size

2. Packet Builder (Encoder)

Converts structured data into packed binary.

Example conceptual input:
Version = 3
Type    = LOGIN
Flags   = ACK | ENCRYPTED
Length  = 128

Becomes:
01110110 10000000

Uses:
bit shifts
masks
OR operations
arithmetic packing

3. Packet Parser (Decoder)
Does the reverse.

Input:
01110110 10000000

Output:
Version = 3
Type    = 22
Flags   = 8
Length  = 128

This is where:
masks
shifts
validation
error handling
show up heavily.

Alignment, checksums, Buffer offsets
